## Hello There

Hi, I'm Brais and this is my first post on my new website.

I'm building it with [Hugo](https://gohugo.io/). I don't like CSS, so I didn't customize the theme, [Coder](https://github.com/luizdepra/hugo-coder), too much.

The domain was mine for some time, I bought it to be able to release in maven central using `com.braisgabin`. And I'm going to use [GitHub](https://github.com/BraisGabin/braisgabin.github.io) to host it, at least for now. I don't want to maintain a server just for this.

A bit about me: Father, Android developer, detekt maintainer, board game enjoyer. Right now I work at the LidlPlus app in the platform team focused on Developer Experience.
I'm starting this blog to share with the world the cool things that I/we do so other people can benefit from it. This is one way to give back to the community what I learned from it.

This is not the first time that I have a blog, I wrote [some posts in the past at medium](https://medium.com/@braisgabin). But medium doesn't work for me anymore so I decided to build my own web. Maybe I port those post here, we will see.

Last point: This blog will be written by me. It can be reviewed by peers and include some of their suggestions, but I will never let you waste your time by pasting something generated with an LLM.
To be honest I had my doubts about starting this blog because I don't like the idea of giving more data to the LLM crawlers. But if the people I read stop writing because of that I would be sad, so I guess that's not a good reason to stop writing.

Welcome and enjoy your stay.
